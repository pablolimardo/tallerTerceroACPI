continue: Saltear una vuelta

El continue detiene la vuelta actual y salta directamente a la siguiente sin salir del bucle.

# Ejemplo: ignorar lecturas erróneas (0) lecturas = [22.5, 0, 24.1, 0, 21.8] total = 0 for t in lecturas: if t == 0: continue # Salta el resto del código y pasa al siguiente t total += t print(f"Sumando lectura: {t}")

Definición y Llamado
📦
Ventaja: En vez de repetir el if para cada habitación, creás una función y la llamás pasando la temperatura de cada zona.
# Definición de la función def analizar_zona(nombre, temp): if temp > 26: estado = "CALOR" else: estado = "OK" return f"{nombre}: {estado}" # Llamado a la función res1 = analizar_zona("Living", 22.5) res2 = analizar_zona("Cocina", 29.1) print(res1) print(res2)
Importante: Las variables creadas dentro de una función (Scope Local) no existen fuera de ella a menos que uses return.
