Bucle for y continue

⚠
Saltear vueltas: continue
Usá continue cuando quieras ignorar un elemento específico y pasar rápido al siguiente sin salir del bucle.
# Ignorar sensores desconectados (valor 0) lecturas = [22.5, 0, 24.1, 0, 21.8] for t in lecturas: if t == 0: continue # Salta el print y sigue con la siguiente lectura print(f"Procesando: {t}°C")

Funciones: Reutilizar código

📦
¿Qué es una función?
Imaginen la maqueta: tenemos 10 habitaciones. En lugar de copiar 10 veces el código del if, creamos una función que lo haga por nosotros pasándole la temperatura.
# Definición de la función def analizar_clima(habitacion, temp): if temp > 26: res = "CALOR" else: res = "OK" return f"{habitacion}: {res}" # Llamado a la función print(analizar_clima("Living", 22.5)) print(analizar_clima("Cocina", 31.0))
def: Define. return: Devuelve el resultado al programa principal.
