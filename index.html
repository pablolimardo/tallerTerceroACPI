Concepto clave¿Qué es un algoritmo?

Un algoritmo es una secuencia finita, ordenada y sin ambigüedades de pasos para resolver un problema. Antes de escribir una sola línea de código, hay que tener claro: ¿cuál es la entrada? ¿cuál es la precondición (qué tiene que ser verdad antes de empezar)? ¿Cuál es la postcondición (qué garantiza el programa al terminar)?

# Ejemplo: algoritmo para clasificar temperatura # ENTRADA: temperatura (float) # PRECONDICIÓN: temperatura > -50 y temperatura < 100 (sensor válido) # POSTCONDICIÓN: el estado es exactamente uno de los cuatro posibles if temperatura < 16: estado = "Frío" elif temperatura <= 26: estado = "Confort" elif temperatura <= 30: estado = "Calor" else: estado = "Alarma"

Variables

Una variable es una posición de memoria con nombre donde guardás un valor para usarlo después.

📦
Concepto base
Variables y estado del programa
🏷️
En el panel de control de la maqueta cada indicador tiene un nombre: TEMP_LIVING, HUM_COCINA, VENTILADOR_ON. Una variable en Python hace lo mismo: dale un nombre descriptivo a cada valor que necesités recordar.
# Variables de la maqueta temp_living = 22.5 # temperatura del living en °C hum_living = 58.0 # humedad relativa en % zona = "Living" ventilador_on = False # el ventilador está apagado umbral_calor = 26.0 # temperatura límite para activar ventilador # Usar y actualizar variables print(temp_living) # → 22.5 temp_living += 0.5 # sube 0.5 °C ventilador_on = True # encender el ventilador
Reglas para los nombres: solo letras, números y guión bajo. Sin espacios, sin tildes, sin empezar con número. temp_living es correcto. temperatura del living es incorrecto.
= no es "igual" — es "asignar": temp_living = 22.5 se lee "la variable temp_living ahora vale 22.5". Para comparar si dos cosas son iguales se usa ==.

El error más común con input(): "22.5" con comillas es un str (texto), no un número. El sensor podría mandar datos así. Para convertirlo y poder operar: float("22.5") → 22.5
# Conversión de tipos — fundamental para trabajar con sensores lectura_raw = "22.5" # viene del sensor como texto temperatura = float(lectura_raw) # → 22.5 (ahora es número) # float → int (pierde los decimales, NO redondea) temp_entera = int(temperatura) # → 22 (corta en 22, no 23) # número → str para armar mensajes msg = f"Zona: Living | Temp: {temperatura}°C | Estado: Confort"

if / elif / else

La selección: el programa evalúa una condición y toma un camino. Solo uno.

🌡️
Estructura de selección
Clasificador de temperatura de la maqueta
🚦
El if evalúa de arriba hacia abajo y ejecuta solo el primer bloque verdadero. El resto se saltea. Es como un termostato que revisa rangos de temperatura en orden.
# Clasificador de temperatura para la maqueta temperatura = float(input("Temperatura (°C): ")) if temperatura > 30.0: print("🔴 ALARMA — activar sistema de enfriamiento") ventilador_on = True elif temperatura > 26.0: print("🟡 CALOR — temperatura elevada") ventilador_on = True elif temperatura >= 16.0: print("🟢 CONFORT — temperatura ideal") ventilador_on = False else: print("🔵 FRÍO — activar calefacción") ventilador_on = False
La indentación (sangría) es obligatoria. Todo el código dentro de un bloque if lleva 4 espacios. En VS Code al escribir el : y presionar Enter, Python lo hace automático.

Bucle for — iteración

La iteración determinada: repetí cuando sabés exactamente cuántas veces.

🔄
Iteración determinada
for en la domótica — recorrer zonas y lecturas
📋
En la maqueta queremos revisar cada zona en orden. El for es perfecto para eso: recorre una lista o un rango, una vez por elemento, en orden, y sabe cuándo terminó.
# Recorrer las zonas de la maqueta zonas = ["Living", "Dormitorio", "Cocina", "Baño"] for zona in zonas: print(f"Revisando: {zona}") # Con range() — las 3 formas for i in range(4): # 0, 1, 2, 3 print(f"Sensor {i}: OK") for hora in range(8, 22): # horas del día: 8 a 21 print(f"Hora {hora}:00 — monitoreando") # Acumulador — promedio de temperatura lecturas = [22.5, 24.0, 21.8, 23.3] total = 0 for t in lecturas: total += t promedio = total / len(lecturas) print(f"Temperatura promedio: {promedio:.1f} °C")

Bucle while — iteración indeterminada

Repetí mientras se cumpla una condición. No sabés de antemano cuántas veces.

⌛
Iteración indeterminada
El corazón del sistema de monitoreo
💡
Un sistema de domótica real nunca para. El while True es el latido: medir → decidir → actuar → esperar → repetir. En Python simulamos esto con un while que itera hasta que el usuario dice "salir".
# Simulación del bucle de monitoreo continuo umbral = 26.0 while True: zona = input("Zona (o 'salir'): ") if zona == "salir": break # sale del while temperatura = float(input("Temperatura (°C): ")) if temperatura > umbral: print(f"🔴 {zona}: {temperatura}°C — ALERTA") else: print(f"🟢 {zona}: {temperatura}°C — OK") print("Sistema de monitoreo cerrado.") # while con condición — esperar hasta alcanzar la temperatura temp_actual = 12.0 while temp_actual < 20.0: print(f"Calentando... {temp_actual}°C") temp_actual += 1.5 # simula el calefactor print("✓ Temperatura de confort alcanzada")

Peligro: loop infinito. Si la condición del while nunca se vuelve False y no hay un break, el programa se cuelga. En el simulador podemos parar con Ctrl+C. En un sistema real, siempre agregá una condición de salida.

Tecnología de Control

La otra cara del proyecto: mientras programamos en Python, en Tecnología de Control aprendemos el hardware que hace todo posible.

🔌
Fundamento
Sistemas de control — qué son y cómo se clasifican
🔄
Un sistema de control toma una medida del mundo real (señal de entrada), la compara con un valor deseado (variable de referencia o setpoint) y genera una señal de salida hacia un actuador para modificar la variable controlada y reducir el error (señal de desviación).
ConceptoDefiniciónEjemplo en la maqueta
Variable controladaLa condición física que queremos mantener o cambiarTemperatura de la habitación
Señal de referenciaEl valor deseado (setpoint) que fijamosTermostato a 22°C
AccionamientoCómo operamos el sistemaManual: prender botón. Automático: for/while en Python.
Tipo de LazoCaracterísticaEjemplo en la maqueta
Lazo abiertoActúa sin medir el resultadoEncender el calefactor por 15 minutos sin revisar temperatura.
Lazo cerradoMide, compara y corrige automáticamenteEncender calefactor hasta llegar exactamente a 20°C.
Control ON/OFFSolo dos estados: encendido o apagadoVentilador: ON si temp>26°C, OFF si temp<=26°C

El if/elif/else que aprendimos en Programación es el controlador ON/OFF. Cuando la temperatura supera el umbral → if activa el ventilador. Cuando baja → else lo apaga. Es lazo cerrado implementado en software.
