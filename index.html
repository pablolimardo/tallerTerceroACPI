Bucles y Continue

🔄
Uso de continue
El continue salta el resto del código en la vuelta actual y pasa directamente a la siguiente. Útil para ignorar datos inválidos.
# Ignorar sensores desconectados (valor 0) lecturas = [22, 0, 25, 0, 21] for t in lecturas: if t == 0: continue # Salta el print print(f"Procesando: {t}°C")

Funciones: Reutilizar Código

Una función es un bloque de código con nombre que realiza una tarea específica.

📦
¿Qué son las funciones?
Imaginen que tienen 10 habitaciones en la maqueta. En lugar de escribir el if/else de temperatura 10 veces, crean una función una sola vez y la "llaman" cada vez que la necesitan.
# 1. Definimos la función (La receta) def analizar_clima(habitacion, temp): if temp > 26: res = "Calor" else: res = "OK" return f"{habitacion}: {res}" # 2. Llamamos a la función (Cocinamos) print( analizar_clima("Living", 22.5) ) print( analizar_clima("Cocina", 31.0) )
Partes de una función:
* def: Palabra para empezar.
* Parámetros: Los datos que recibe (entre paréntesis).
* return: El resultado que la función nos devuelve.
